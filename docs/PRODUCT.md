# Producto

## Visión

Un descargador de escritorio claro, confiable y personalizable que concentra distintos sitios en un solo flujo.

## MVP Definition

- Windows primero; arquitectura preparada para separar interfaz y motores.
- Pegar, analizar y descargar un enlace admitido por yt-dlp.
- Video/audio, calidad, contenedor, carpeta, cola y cancelación.
- Tema automático, configuración persistente y canal GitHub configurable.
- Actualización y reparación independiente de motores.

## Límites

- No elude DRM ni controles de acceso.
- La compatibilidad real sigue la matriz de extractores de yt-dlp.
- Android/iOS queda como evolución posterior, no como parte del instalador Windows.
